Analisa (AHSP)

Centang file AHSP yang mau dipakai di model ini; analisa dan harga dasarnya tampil di pilihan pekerjaan. Kalau dua file punya kode yang sama, file yang lebih atas dipakai.
Format file AHSP 
{
  "meta": { "nama": "AHSP Kota Saya 2026", "versi": "1.0" },
  "harga_dasar": [
    { "kode": "L.01", "jenis": "upah", "nama": "Pekerja", "satuan": "OH", "harga": 120000 }
  ],
  "ahsp": [
    { "kode": "1.1", "divisi": "Pekerjaan Tanah", "kategori": "Galian",
      "uraian": "Galian tanah biasa", "satuan": "m3",
      "komponen": [ { "kode": "L.01", "koef": 0.75 } ] }
  ]
}

jenis: upah, bahan, atau alat. Kode U.nnn (analisa) dan C.nnn (harga dasar) dipakai analisa buatan sendiri, jadi dilewati kalau ada di file.

Excel: tombol Excel di tiap file mengekspor format AHSP (sheet AHSP + DHSP) yang bisa diedit lalu ditambahkan lagi di sini. Untuk mengisi dari nol, unduh Template Excel (sheet Analisa, Komponen, Harga Dasar). Hanya dua format ini yang bisa diimpor; Excel lain ditolak.

Daftar Harga

Daftar harga dipisah dari analisa. Ekspor harga ke Excel dari tab Harga Dasar (atau unduh Template Excel kosong), isi di Excel, lalu impor di sini (.xlsx atau .json). Harga yang cocok menggantikan harga bawaan file AHSP; harga yang Anda ketik di model ini tetap paling atas.
